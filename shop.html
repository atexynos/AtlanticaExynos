🛒 Shop

Top up donasi, item langka, dan paket spesial untuk mendukung server Atlantica Classic V3 Exynos.

Klik ikon ✎ pensil di pojok kanan atas tiap kartu untuk mengubah nama, harga, foto, kategori, atau link order. Pemain klik tombol Pesan untuk order lewat admin.

Foto default tiap slot diambil dari folder assets/shop/ (terpisah dari folder assets/news/ milik halaman utama) — cukup taruh gambar dengan nama item1.jpg, item2.jpg, item3.jpg, dst di sana sesuai urutan slot. Atau upload langsung lewat form edit, tanpa perlu ke GitHub.

Sudah selesai edit shop? Klik tombol di bawah untuk unduh file shop.html terbaru, lalu upload/replace ke GitHub kamu.
