# Atlantica Classic V3 Exynos — Admin

Website data is now embedded directly in `index.html`.

Workflow:
1. Open `index.html` in the browser.
2. Login Admin.
3. Edit Ranking / News / Server Information / Download / Manual Patch.
4. Click **Simpan** in each editor.
5. Click **Download index.html** in the Ranking toolbar.
6. Upload/replace only `index.html` on GitHub Pages.

No `data/site-data.js` is required anymore.

Keep the `assets/`, `shop.html`, and `streamer.html` files/folders because the site still uses them.
